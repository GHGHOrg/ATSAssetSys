Markers

  1. Last backup line (section 9, C15): the export moment with the device's time zone abbreviation, or "never backed up". It is information only; the export is in Backup and restore (10e).
  2. The More list, in this order: Net Worth (Total) (view 2), Allocation (view 4, opens on the first portfolio), Realized gains (view 5), Backup and restore (10e). Settings is not a list row: it is a gear icon at the top right of the More screen and opens Settings (frame B); the badge 2 marks both. The icon carries the label "Settings" for TalkBack, so its meaning does not rest on the picture, and its touch target is at least 48 dp (section 6, Accessibility). Allocation and Net Worth (Total) are reached here as well as from the other tabs (navigation outline).
  3. Security: Auto-lock and Screenshot window. Each row shows its current value and opens a dialog (frame C).
  4. Prices: the price source, with its current value (frame D).
  5. Navigation: tab order, with the current order as text.
  6. Lists: Sectors and Geographies, each with its number of values. Each opens its list screen (frame F).
  7. Auto-lock is one choice of four (section 9), the default marked. It takes effect at once and is saved as a setting. A restored file can set a weaker one (section 9, known limit).
  8. Screenshot window: always off at start. The button asks for a fingerprint or the phone PIN each time. While on, the row shows the time left and Turn off. It ends after 3 minutes or when you leave the app, never survives a restart and is not saved (section 9). It is not selective, so a line says anything can capture the screen during it.
  9. Price source: a pick from the sources the app ships (placeholders). Use this source confirms. Online, the app runs the sweep over every held instrument, hidden holdings included. Offline, the change is allowed with a warning and no sweep (section 7).
  10. Result lines, plain text with no pop-up: after a sweep, the tickers the new source could not price, which keep their last price marked stale; offline, the warning that prices were not refreshed. The new source stays selected either way. Transactions, lots, the verified flag and manual classification are not touched (section 7).
  11. Tab order: one row per tab with Up and Down buttons, not dragging, so it works with TalkBack. The bottom bar follows the new order at once. The order is a setting in the backup file (section 8).
  12. List screen (4.9): each value with the number of holdings that use it (hidden holdings count) and the source texts that map to it after a rename ("Also matches", read only; a Design addition). Rename updates every holding using the value and remembers the source's original text. Delete is offered on every value and is blocked while any holding uses it.
  13. Add value: a new value is picked from the list later; the source can also add values on its own (4.9).
  14. Add and Rename use the same Name field. A name that matches an existing value or remembered text, ignoring case and spaces (D7), is refused with the text kept in the field.
  15. Messages are plain text with a leading "Not saved" or "Not deleted", so meaning never rests on color. A blocked delete names the holdings count and says hidden holdings count (4.9). A rename confirms that the old source text still maps to the new name.
  16. Edit picker (view 6, marker 6): opened from Edit on the Classification tab, one pick from the matching list, no typing (4.9). Save sets the override; Clear override stays on the Classification tab. The line pointing to Settings is a Design addition.
  17. Format only: with an empty list the picker shows one plain line and no Save.

Touch targets are at least 48 dp and text follows the font size setting; the sketches are not to scale. TalkBack reads each row as its name and current value, and a radio choice as selected or not selected. Wording is placeholder (D9).
