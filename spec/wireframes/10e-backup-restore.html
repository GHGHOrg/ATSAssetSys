Markers

  1. Last backup line, as in More (section 9): the export moment in the device's time zone with its abbreviation (C15), or "never backed up".
  2. Back up now starts the export, the same action as the button on the Overall banner. Android's file screen lets you choose the location (frame B, marker 5).
  3. Restore from backup file starts the wizard at step 1. The line says it replaces everything and needs internet.
  4. Offline, Restore is inactive (dashed, not tappable, read by TalkBack as unavailable) and a line says why. The wizard cannot be started (section 8, step 1).
  5. The export writes one file in the format of section 8 to the place you choose. Suggested name backup-YYYY-MM-DD.csv (device time zone, C15).
  6. Result of an export: plain text. Only a completed export updates the last backup date; a cancelled or failed export says so and changes nothing (G2).
  7. Step 1: Choose file opens Android's file screen; the file name is shown, and Check file starts step 2. The app reads only the file you pick.
  8. The date note of section 6 sits next to the date format help. Design addition: the format help line.
  9. Step 2: two phases, reading and rule checks, then verifying every ticker still held at the end of the file with the price source selected before the restore (D6). Verification starts only if the first phase found no errors (section 8, steps 2 and 3). Cancel returns to step 1. Nothing is deleted.
  10. Error report (section 8): "N errors in M lines", then each error with its line, its column when one applies, and the reason; a dependent row says "depends on line N". It stays on screen and scrolls. Plain text, no meaning by color.
  11. Copy report copies the text shown and nothing else, and is the only copy action in the app (C16). It is not a backup. Choose another file returns to step 1.
  12. Ticker errors come in a second round and name the ticker and the source. A file-level failure (not UTF-8, header, version) uses the same layout with "File" in place of a line.
  13. Step 3: counts of portfolios, transactions and cash entries, now versus in the file (section 8, step 5). Transactions are buys, sells, splits and reversals; trade cash lines are not counted.
  14. The resulting cash balance and the number of holdings with shares, to compare with real life (approved addition to intent v52).
  15. Format only: on a fresh install there is nothing to replace, so only the file's summary shows and there is no export offer or typed confirmation (G1, decision 3). Continue becomes Restore.
  16. Step 4 export offer: Back up now is optional and starts the same export. A completed one shows "Backup saved" here. Design addition: the line that restoring cannot be undone.
  17. Typed confirmation: Replace all data stays inactive until the word matches. Delete and load then happen as one action, so the app is never left empty in between (section 8, step 7). Design addition: the word RESTORE.
  18. Step 5, success: the counts loaded, the "no price" note, and the reset last-backup state (section 8, step 7). Go to Overall opens the normal screens. There is no way back into the wizard.
  19. Step 5, failure: if the write itself fails, nothing is changed and the screen says so with a Close button only. Design addition.

Android's Back returns one step in steps 1 to 4 and leaves the wizard from step 1; nothing has been changed until Replace all data. A restart or an auto-lock relock ends the wizard, and it starts again from step 1 (a Design addition, to confirm). Touch targets are at least 48 dp and text follows the font size setting; the sketches are not to scale.
