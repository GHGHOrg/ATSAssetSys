Choices made in this drawing, for you to confirm. Everything else follows D-17 and D-31 to D-35.

  1. Settings opens from Lucide's settings icon at the right of the More band, 48 to tap, labelled "Settings" for TalkBack (marker 2).
  2. On More, the last backup is a read-only dense row in its own card; the destinations are tappable rows with a chevron (five with About, added to frame A after acceptance as D-36's amendment).
  3. Settings sections are a medium 14 secondary heading over a card; each row shows its name in 16 with the current value under it in secondary 14, so long values ("Every time I leave the app") never squeeze the name.
  4. A new radio button: a 20 circle with a 2 outline, selected adding a 10 dot, both in the check color (navy 9 light, gold dark), rows 48 tall; "default" tagged in Asap Condensed 12. To be added to the Component Catalog.
  5. A choice that only saves (auto-lock) applies on tap, and its dialog has Close only; a choice with side effects (price source) confirms with a gold button and Cancel.
  6. The screenshot window's actions are gold (Allow, Turn off: each the one main action where it shows); while on, its row shows the time left in medium and D-34's warning line.
  7. Results on Settings and list screens are D-33's notice banner (the source sweep, offline, renamed); a refused delete is D-31's blocked card; a refused name is on the field.
  8. Tab order uses Lucide arrow-up and arrow-down as 48 icon buttons with no outline, read by TalkBack as "Move … up/down", disabled (38%) at the ends. A new part: the icon button.
  9. On a list screen, Rename and Delete are small text buttons under each value's lines, not on its first line, so a long value name keeps its room; Add value is the gold foot.
  10. The Edit picker is a screen with radio rows in a card and the entry foot (Save gold, Cancel text); its empty state is the nothing-to-enter card.

Not drawn: these at 200% font, the Add value dialog (as I without the refusal), the Geographies list, the screenshot window's PIN prompt (the system's). Icons are Lucide at stroke 2, drawn inline from its path data as Claude knows it.
