# Wireframes

Companion to spec/spec.md section 6 (Views). One file per wireframe, approved one at a time.
An approved file is not edited again unless you reopen it. All wording in the wireframes is
placeholder (D9, decided in Build). Colors are placeholders; the real ones are chosen in Build
for both themes (spec.md section 6, Number format and color).
